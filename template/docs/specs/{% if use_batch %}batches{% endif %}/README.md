# バッチ設計書

画面を持たない処理（定期実行・外部からの受信を契機に動く処理）の個票を置く。

- 1 バッチ 1 ファイル。`BATCH-<連番>-<短い名前>.md`
- 雛形は `_template.md`。`BATCH-900` は雛形のサンプルなので**全判定の母集団から除外する**
- 採番は P02、中身は P04 で書く
