# 01 システム価値（なぜ作るか / 誰にどんな価値を）

配置するもの:
- システムコンテキスト図（アクター・外部システム）
- 要求モデル（機能要求 REQ-xxx / 非機能要求）

図は `../../assets/` に実体を置き、ここから参照する。
Mermaid で本文に埋めてもよいが、**ID の定義は必ず表に書く**
（整合チェックはコードブロックを除外してから ID を拾うため、図の中だけの ID は未定義扱いになる）。
図の配色・凡例の描き方は `../diagram-notation.md` に従う。

システム化の対象・対象外の確定結果は `../03-boundary/README.md` が正本。ここには置かない。
