# 画面 × UC × API 対応表

画面とAPIは多対多。ここを唯一の対応表とし、両側の個票から参照する。
API変更時の影響画面、画面変更時の依存APIをここで追跡する。

| 画面 | UC | API | 用途 |
|------|-----|-----|------|
| SCR-001 ログイン | UC-001 認証する | API-001 ログイン | 資格情報検証 |

<!-- 行の追加例（実体を作ってから追記する。実体の無いIDを書くと validate-docs が ERROR にする）
| SCR-002 ダッシュボード | UC-002 概況を見る | API-002 一覧取得 | 初期表示 |
-->

更新ルール:
- 新API/新画面を追加したら必ずこの表に行を足す
- IDはファイル名の接頭辞（SCR-/UC-/API-）とキー一致させる
- `scripts/docs-validate/validate-docs.py` が「個票あり・表に無い」「表にあり・個票が無い」を両方向で検査する
