# デザイン（P03）

HTML モックの置き場と、画面型のパターン定義。

- **モックの正本はこのディレクトリの HTML**。ブラウザで直接開けること（ビルド不要）。
- モックは**見た目の合意のための使い捨て**。そのまま実装へ持ち込む前提で作らない。
- 作り方と判定基準は `docs/prompts/p03-design.md` にある。

## 構成

```
docs/design/
  README.md          ← このファイル。パターン定義と画面の割り当て
  mocks/
    SCR-xxx-<短い名前>.html
    SCR-xxx-<短い名前>-b.html   ← 比較案がある場合
```
